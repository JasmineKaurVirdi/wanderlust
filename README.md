# Wanderlust – Full-Stack Accommodation Listing Website

Wanderlust is a full-stack accommodation listing web application where users can explore, search, create, edit, and manage property listings.

## 🚀 Live Demo

https://wanderlust-rygy.onrender.com/listings

## 🛠️ Tech Stack

- JavaScript
- Node.js
- Express.js
- MongoDB
- Mongoose
- EJS
- Bootstrap
- Leaflet
- Passport.js
- Git & GitHub

## ✨ Features

- User registration and login
- Create, edit and delete listings
- Search listings by location
- Category-based filtering
- Image upload for listings
- Ratings and reviews
- Location-based map integration
- Responsive user interface
- Flash messages and form validation

## 📁 Project Structure

The project follows a structured MVC-style architecture with separate routes, controllers, models, views and middleware.

## 💻 Run Locally

1. Clone the repository
2. Install dependencies:

   npm install

3. Create a .env file with the required environment variables.
4. Start the application:

   npm start

5. Open the application in your browser.
